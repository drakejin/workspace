# sample-workspace — 에이전트 규칙

memory-mcp 체험용 가상 meta-repository 다. 규칙은 루트 워크스페이스의 CLAUDE.md 를 줄인 것이다.

1. **작업을 시작하면 `search_memory` 를 먼저 부른다** (도구가 있으면). 파일 트리를 뒤지기 전에. 질의에는 서비스명·함수명·필드명 같은 식별자를 그대로 넣는다.
2. 결과의 `source_path` 를 Read 해서 원문을 근거로 답한다. 근거가 된 문서 경로를 함께 적는다.
3. 검색 도구가 없거나 결과가 없을 때만 디렉토리를 훑는다. 이때도 전체를 읽지 말고 그 디렉토리의 `INDEX.md` 부터 읽는다.
4. 60일보다 오래된 맥락이 필요하면 `list_cold` 로 확인하고, `restore_cold` 전에 사용자에게 "cold 인덱스 X가 있는데 복원할까요"를 묻는다.
